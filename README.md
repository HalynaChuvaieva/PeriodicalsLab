# Лабораторна робота №2 Варіант 11: Періодичні видання

Консольний Java-додаток, розроблений для парсингу, валідації та обробки XML-документів предметної області "Періодичні видання" (газети, журнали, буклети).

## Основний функціонал
* **Розбір XML:** реалізовано зчитування даних з XML-файлу за допомогою трьох різних парсерів: **DOM**, **SAX** та **StAX**.
* **Валідація (XSD):** перевірка структури та типів даних вхідного XML-документа за допомогою XSD-схеми (перевірка атрибутів, граничних значень та підписних індексів).
* **Трансформація (XSL):** перетворення початкового XML-файлу в новий формат із групуванням видань за їхнім типом.
* **Об'єктно-орієнтована модель:** дані конвертуються в Java-об'єкти з дотриманням принципів ООП (інкапсуляція, поліморфізм) та перевіркою бізнес-правил варіанта.
* **Сортування:** використання інтерфейсу `Comparator` для сортування колекцій об'єктів за обсягом сторінок та назвою.

## Технології та інструменти
* **Мова програмування:** Java 21
* **Система збірки:** Maven
* **Логування:** SLF4J + Logback (замість стандартного виводу в консоль)
* **Тестування:** JUnit 5 (повне покриття парсерів, валідації та бізнес-логіки)

## Структура проєкту
* `src/main/java/` — вихідний код (моделі, парсери, утиліти).
* `src/main/resources/` — файли даних (`papers.xml`, `papers.xsd`, `transform.xsl`) та конфігурація логера.
* `src/test/java/` — Unit-тести.
